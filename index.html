Airbnb Amsterdam price prediction

An end-to-end regression pipeline for about 5,900 Amsterdam listings: leakage-safe preprocessing, automatic feature selection, and cross-validated comparison of twelve models and two ensembles, with a held-out evaluation that reports the effect of extreme prices openly.

What the pipeline does

  • Splits train and test first. Medians, category levels, rare-category lists and TF-IDF vocabularies are fitted on the training data only.
  • Excludes identifiers and a revenue column derived from the target, which would leak the answer.
  • Ranks features with correlation, mutual information, VIF, random-forest and permutation importance, then saves the shortlist automatically.
  • Tunes every model with 5-fold cross-validation on the training set. The test set is used once, for the final evaluation.

What it found

  • Gradient boosting on all features beat every linear model and every model limited to the shortlist.
  • The shortlist dropped features that tree models use, such as bathrooms, host listing counts and text. A shortlist that suits interpretation does not automatically suit prediction.
  • Two test listings priced at 80,018 push the full-test R² to about 0 for every model, so the results are reported both with and without them.

Limitations: one random 80/20 split, deliberately small tuning grids, and cross-validation scores for the shortlist that are slightly optimistic because the shortlist used all training rows. Details are in the repository README.
